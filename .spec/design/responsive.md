# Responsive Rules

## Desktop

Breakpoint:
>= 1024px

Layout:
full horizontal toolbar

Task card:
single row

Modal:
right side sheet

---

## Tablet

Breakpoint:
768px–1023px

Filter bar:
may wrap

Container padding:
reduced

Task cards:
slightly compact

---

## Mobile

Breakpoint:
< 768px

Layout changes:

Header:
compact

Filters:
horizontal chips

Task card:
stacked metadata

Badge alignment:
right

Floating add button:
allowed

Task spacing:
reduced

Padding:
16px

---

## Mobile Task Card

Structure:

[title]

[metadata]

[badges]

No overflow.

No horizontal scrolling.

---

## Forbidden

Do not:

- hide important actions
- collapse task title
- introduce separate mobile routes

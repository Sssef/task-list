# Animations

## Purpose

Microinteractions only.

Animation must remain subtle.

---

## Timing

Default:
200ms

Slow:
300ms max

Easing:
ease-out

---

## Task Card Hover

Effects:

- shadow-sm
- border emphasis

No scale transform.

---

## Button Hover

Add Task button:
slight brightness change

Ghost buttons:
soft background

---

## Modal

Open:
slide + fade

Close:
reverse animation

Duration:
200ms

---

## List Changes

Task added:
soft fade-in

Task removed:
soft fade-out

No bounce.

No spring animation.

---

## Loading

Skeleton only.

No spinners.

---

## Forbidden

Do not use:

- parallax
- bounce
- elastic transitions
- exaggerated motion
- motion-heavy onboarding

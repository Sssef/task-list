# Phase 08: Deployment

## Goal

Deploy application publicly.

No application changes beyond deployment needs.

---

## Required Reading

```txt
deployment/github-pages.md
deployment/ci.md
```

---

## Scope

Implement ONLY:

### Deployment

Configure:

* GitHub Pages
* Vite base path
* production build
* deployment workflow

---

### CI

Configure:

* GitHub Actions
* build verification

---

### Documentation

Update:

* README
* install instructions
* run instructions
* deploy instructions

---

## Verification

Verify:

* production build succeeds
* no broken assets
* refresh works
* routes work
* GitHub Pages deployment works

---

## Forbidden

Do NOT implement:

* feature changes
* redesign
* refactoring
* architecture changes

No product scope changes.

---

## Output

Application publicly accessible.

---

## Definition of Done

Phase complete when:

* deployed URL works
* build passes
* CI passes
* README updated
* no runtime errors exist

STOP after completion.
